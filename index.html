Arquitetura do Fluxo de Publicação

Portal de acesso aberto ao público, sem necessidade de login para consultar o projeto e testar o preparador de metadados.

ETAPA 1

Autenticação OAuth2

O proprietário do canal autentica sua conta via TikTok Login Kit, concedendo acesso exclusivo aos escopos autorizados.

ETAPA 2

Renderização & Legendas

Vídeos verticais 9:16 em H.264/AAC são montados com narração histórica, acervos públicos e legendas palavra a palavra.

ETAPA 3

Content Posting API

O aplicativo envia o arquivo MP4 com título, hashtags e privacidade configurável diretamente para a conta conectada.

Validador de Metadados (Content Posting API)

Ferramenta aberta para pré-visualizar título, hashtags e nível de privacidade antes do envio via API oficial.
