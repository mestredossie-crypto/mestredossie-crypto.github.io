Política de Privacidade

Mestre dos Arquivos — Última atualização: 11 de Novembro de 2026

A sua privacidade é fundamental para nós. Esta Política de Privacidade descreve de maneira transparente como o aplicativo Mestre dos Arquivos coleta, utiliza, armazena e protege suas informações ao utilizar nossos serviços e a integração oficial com a API do TikTok.

1. Dados Coletados e Finalidade

Coletamos unicamente os dados estritamente necessários para o funcionamento das publicações automatizadas:

  • Credenciais de Acesso (Tokens OAuth2): Tokens fornecidos com seu consentimento via fluxo oficial do TikTok para permitir o upload de vídeos autorizados.
  • Informações de Perfil Básico: Nome de usuário ou identificador de conta fornecido pelo TikTok para confirmação de conexão.

2. Não Compartilhamento e Não Venda de Dados

Não vendemos, não alugamos e não compartilhamos quaisquer dados pessoais ou credenciais com terceiros, parceiros comerciais ou redes de publicidade. Os dados destinam-se exclusivamente à comunicação direta e segura com a API do TikTok.

3. Armazenamento Seguro e Criptografia

Todos os tokens de autenticação são transmitidos via conexões criptografadas (HTTPS/TLS) e armazenados de maneira segura na infraestrutura privada do usuário, em conformidade com as melhores práticas de cibersegurança.

4. Retenção e Exclusão de Dados

O usuário pode solicitar a revogação de acessos e a exclusão imediata de todos os tokens e registros a qualquer momento. Basta revogar as permissões no painel de aplicativos do TikTok ou enviar uma solicitação diretamente para nosso canal de suporte.
